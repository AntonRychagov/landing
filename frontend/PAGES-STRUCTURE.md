# Структура страниц лендинга

## Основные страницы

### 1. Главная страница (`/`)
- **Путь**: `app/page.tsx`
- **Описание**: Основной лендинг со всеми секциями
- **Секции**:
  - Hero (главный экран)
  - О себе
  - Портфолио (сетка проектов)
  - Видео галерея
  - Награды
  - Отзывы
  - Контакты
  - Footer

### 2. Страница "О себе" (`/about`)
- **Путь**: `app/about/page.tsx`
- **Описание**: Расширенная информация о сценаристе/режиссере
- **Содержание**:
  - Детальная биография
  - Образование
  - Философия творчества
  - Интересы
  - Статистика (проекты, награды, годы работы)
  - Секции наград и отзывов
  - CTA кнопки

### 3. Страница контактов (`/contact`)
- **Путь**: `app/contact/page.tsx`
- **Описание**: Страница для связи
- **Содержание**:
  - Форма обратной связи
  - Контактная информация
  - FAQ (часто задаваемые вопросы)

### 4. Детальная страница проекта (`/projects/[id]`)
- **Путь**: `app/projects/[id]/page.tsx`
- **Описание**: Подробная информация о конкретном проекте
- **Динамические маршруты**:
  - `/projects/project-1`
  - `/projects/project-2`
  - `/projects/project-3`
  - `/projects/project-4`
- **Содержание**:
  - Hero секция с постером
  - Описание проекта
  - Видео (если есть)
  - Галерея изображений
  - Награды и номинации
  - Ссылка на просмотр
  - Похожие проекты

### 5. Страница 404 (`/not-found`)
- **Путь**: `app/not-found.tsx`
- **Описание**: Страница для несуществующих маршрутов
- **Содержание**:
  - Сообщение об ошибке
  - Кнопки навигации

## Компоненты

### Навигация
- **Header** (`app/components/Header.tsx`)
  - Фиксированная навигация сверху
  - Адаптивное меню для мобильных устройств
  - Подсветка активной страницы
  - Прозрачный фон при прокрутке

### Общие компоненты
Все компоненты находятся в `app/components/`:
- `Hero.tsx` - главный экран
- `About.tsx` - секция "О себе"
- `Portfolio.tsx` - сетка проектов
- `VideoGallery.tsx` - галерея видео
- `Awards.tsx` - награды
- `Testimonials.tsx` - отзывы
- `Contact.tsx` - форма контактов
- `Footer.tsx` - футер

## Навигация

### Главное меню (Header)
- Главная → `/`
- О себе → `/about`
- Портфолио → `/#portfolio` (якорная ссылка на главной)
- Видео → `/#videos` (якорная ссылка на главной)
- Награды → `/#awards` (якорная ссылка на главной)
- Контакты → `/contact`

### Переходы между страницами
- Клик на проект в портфолио → `/projects/[id]`
- Кнопка "Назад" на странице проекта → `/#portfolio`
- Ссылки в Footer → соответствующие разделы

## Особенности реализации

1. **Static Site Generation (SSG)**
   - Все страницы генерируются статически при сборке
   - Страницы проектов предгенерируются для всех проектов

2. **Адаптивный дизайн**
   - Все страницы адаптированы для мобильных устройств
   - Мобильное меню в Header

3. **Оптимизация**
   - Изображения оптимизируются через Next.js Image
   - Ленивая загрузка для улучшения производительности

4. **Типизация**
   - Все данные типизированы через TypeScript
   - Типы определены в `data/types.ts`

## Структура файлов

```
app/
├── components/          # Переиспользуемые компоненты
│   ├── Header.tsx      # Навигация
│   ├── Hero.tsx        # Главный экран
│   ├── About.tsx       # О себе
│   ├── Portfolio.tsx   # Портфолио
│   ├── VideoGallery.tsx
│   ├── Awards.tsx
│   ├── Testimonials.tsx
│   ├── Contact.tsx
│   └── Footer.tsx
├── projects/
│   └── [id]/
│       ├── layout.tsx  # Метаданные для проектов
│       └── page.tsx    # Детальная страница проекта
├── about/
│   └── page.tsx        # Страница "О себе"
├── contact/
│   └── page.tsx        # Страница контактов
├── layout.tsx          # Корневой layout с Header
├── page.tsx            # Главная страница
└── not-found.tsx       # Страница 404
```

## Добавление новых страниц

1. Создать папку в `app/` с именем маршрута
2. Создать `page.tsx` внутри папки
3. Добавить метаданные (опционально)
4. Добавить ссылку в Header (если нужно)

## Добавление новых проектов

1. Добавить проект в `data/portfolio-data.ts`
2. Страница автоматически сгенерируется при следующей сборке
3. URL будет: `/projects/[id проекта]`
