# Инструкция по настройке GitHub Pages

## ✅ Что уже сделано:
- ✅ Настроен Next.js для статического экспорта
- ✅ Создан GitHub Actions workflow для автоматического деплоя
- ✅ Все изменения запушены в репозиторий

## 🔧 Что нужно сделать СЕЙЧАС:

### Шаг 1: Изменить Source в настройках GitHub Pages

1. **Откройте страницу настроек** (должна быть открыта в браузере):
   https://github.com/AntonRychagov/landing/settings/pages

2. **Найдите раздел "Build and deployment"**

3. **В поле "Source"** выберите:
   - ❌ НЕ "Deploy from a branch"
   - ✅ **"GitHub Actions"** (выберите этот вариант)

4. **Сохраните изменения** (если требуется кнопка Save)

### Шаг 2: Проверить статус деплоя

1. **Откройте вкладку Actions** (должна быть открыта в браузере):
   https://github.com/AntonRychagov/landing/actions

2. **Найдите workflow "Deploy Next.js to GitHub Pages"**

3. **Если workflow не запущен:**
   - Нажмите кнопку **"Run workflow"** (справа вверху)
   - Выберите ветку **main**
   - Нажмите **"Run workflow"**

4. **Дождитесь завершения:**
   - Должна появиться зеленая галочка ✅
   - Обычно занимает 2-3 минуты

### Шаг 3: Проверить сайт

После успешного деплоя ваш сайт будет доступен по адресу:
**https://antonrychagov.github.io/landing/**

---

## ⚠️ Если что-то не работает:

1. **Проверьте логи workflow:**
   - Откройте последний запуск workflow
   - Проверьте, нет ли ошибок (красные крестики)
   - Если есть ошибки - скопируйте текст ошибки

2. **Убедитесь, что Source изменен:**
   - Вернитесь в Settings > Pages
   - Должно быть выбрано "GitHub Actions"

3. **Попробуйте перезапустить workflow:**
   - В Actions нажмите "Run workflow" еще раз

---

## 📝 Примечания:

- После изменения Source на "GitHub Actions", GitHub больше не будет показывать README.md
- Сайт будет автоматически обновляться при каждом push в ветку main
- Первый деплой может занять немного больше времени
